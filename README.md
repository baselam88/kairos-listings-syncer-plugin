# Local Listings Syncer

Audits name/address/phone/hours consistency across Google, Yelp, and directories and returns the fix checklist.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Compare the business's canonical details against its live listings (fetched), output mismatch table + exact fix per platform. Outcome = audit + fixes, never a promised rank lift.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Local Listings Syncer to help me: audits name/address/phone/hours consistency across Google, Yelp, and directories and returns the fix checklist — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.

This plugin also connects to the Local Listings Syncer service endpoint (`kairos-listings-syncer-mcp`) for the live checks described in the skill; the guided workflow works the same in chat.
